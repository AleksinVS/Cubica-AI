## Результат для пользователя

Создан автономный HTML/CSS/JS-прототип, который показывает исходную карту
«Начальная транспортная сеть» и поверх неё интерактивные инженерные выноски для
всех 23 шестерёнок. Пользователь может выбрать узел, увидеть и изменить пять
показателей, управлять масштабом, скрыть выноски и сбросить демоданные. Для
зелёных станций начальной сети прототип также показывает стоимость доставки на
соседние станции в виде монет и подсвечивает кратчайший маршрут до выбранного
по диаграмме назначения. Диаграммы можно перетаскивать, а увеличенные монеты с
читаемыми номиналами размещаются непосредственно под диаграммой соответствующей
соседней станции и перемещаются вместе с ней.

Статус: `completed`.

## Границы

- Прототип относится только к игре «Карты, деньги, поезда» и хранится в
  `draft/trains/`.
- Исходная карта остаётся неизменной и используется как фоновое изображение.
- Прототип не подключается к runtime, не меняет манифесты, общие контракты,
  хранение состояния или доверительные границы платформы.
- Данные демонстрационные и существуют только в памяти страницы.
- Зелёные узлы `01`–`09` образуют захардкоженный тестовый граф по видимым
  железным дорогам; серые терминалы `10`–`23` в этом прототипе недоступны для
  маршрута.

## Критерии приёмки

- На карте присутствуют ровно 23 выноски с номерами `01`–`23`.
- В каждой выноске ровно пять колонок с уникальными высотами `5`–`9`;
  заполненные сегменты имеют цвет рамки, потенциальные сегменты серые.
- Выноски масштабируются вместе с картой и сохраняют привязку к шестерёнкам.
- Зелёная шестерёнка выбирает исходную станцию мышью или клавиатурой, а
  диаграмма отдельно выбирает пункт назначения.
- Короткое нажатие на диаграмму выбирает назначение; движение указателя больше
  защитного порога переносит диаграмму и не вызывает маршрут после отпускания.
- Сфокусированную диаграмму можно перемещать стрелками (с `Shift` — крупным
  шагом); карта также поддерживает стрелки и не может быть полностью уведена из
  видимой области.
- После выбора станции возле каждого непосредственного соседа появляется от
  одной до десяти крупных монет разного размера, цвета и номинала; группа
  центрируется под диаграммой соседа и следует за ней при переносе.
- Кратчайший путь подсвечивается по геометрии видимых рельсов; для терминалов
  вне начальной сети показано состояние «маршрут ещё не открыт».
- Работают скрытие выносок, сброс демоданных, масштабирование и перемещение
  карты.
- Прототип открывается напрямую в современном браузере без установки
  зависимостей.

  успешно.

  успешно.
- Контрольные кратчайшие пути `01→04`, `05→08`, `02→04`, `08→03` — успешно.
- Все локальные ресурсы HTML существуют; внешних зависимостей нет.
- `git diff --check` для изменённых файлов — успешно.

  запрашивал управление браузером в рамках этого прототипа.
