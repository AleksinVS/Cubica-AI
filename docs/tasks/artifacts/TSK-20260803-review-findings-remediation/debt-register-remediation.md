# Устранение расхождений реестра технического долга

Проверка `verify:legacy` теперь сопоставляет статус каждой записи технического
долга с разделом и статусом той же записи в реестре временных решений. Она также
отвергает повторяющиеся идентификаторы и повреждённые строки Markdown-таблицы.

| Расхождение | Исправление | Машинное доказательство |
| --- | --- | --- |
| `LEGACY-0036` одновременно выглядел активным и закрытым | Архитектурный разрыв перенесён в архив как закрытый; незавершённая реализация хостируемой авторской студии выделена в `LEGACY-0077` | Отрицательный самотест запрещает активную запись в архивном разделе и закрытую запись в текущем разделе |
| `LEGACY-0038` ссылался на закрытый идентификатор | Связь границы доверия стороннего кода переведена на действующий `LEGACY-0077` | `verify:legacy` требует существования и совпадения всех активных строк |
| Повтор идентификатора мог пройти незамеченным | Проверяются повторы отдельно в CSV и Markdown-реестре | Два отрицательных самотеста создают повторы и требуют отказа |
| Разделитель `|` внутри кода или экранированного текста сдвигал столбцы | Добавлен разбор строки Markdown с учётом экранирования и фрагментов кода | Текущие 81 строка долга и 81 строка реестра сопоставляются без ручных исключений |

Свежий результат после исправлений: `npm run verify:legacy` — успешно, 81 запись
долга сопоставлена с 81 записью реестра.
