# Реестр автономных решений TSK-20260803

## 2026-08-27 — Стандартные маршруты закрываются в коде

- Решение: стандартные CRUD-маршруты `order`, `purchase` и `link`, не требуемые
  пользовательским сценарием, исключаются конфигурацией core router. Доступные операции
  остаются только в явно ограниченных контроллерах.
- Основание: права ролей Strapi хранятся вне Git и не дают переносимого fail-closed
  доказательства для нового окружения тестового VPS.
- Упрощение: не вводится общий слой политик или новый сервис авторизации; используется
  штатная конфигурация маршрутов Strapi 5.
- Пересмотр: если каталог получит подтверждённый пользовательский сценарий чтения
  отдельного заказа, покупки или ссылки стандартным API, для него нужен отдельный
  объектно-ограниченный маршрут и негативная проверка чужого объекта.

## 2026-08-27 — Платёжная заглушка остаётся двухсторонне выключаемой

- Решение: тестовая оплата сохраняется для тестового VPS, но автоматические браузерные
  учётные данные и регистрация удаляются. Вызов требует уже выполненного входа, явного
  непромышленного клиентского признака и существующего серверного
  `PAYMENT_STUB_ENABLED=true`.
- Основание: заглушка нужна принятому тестовому запуску, но секретоподобные фиксированные
  данные пользователя и неявный обход входа не должны попадать в промышленный сценарий.
- Пересмотр: удалить клиентский путь полностью после подключения принятого платёжного
  сценария для тестового VPS.
