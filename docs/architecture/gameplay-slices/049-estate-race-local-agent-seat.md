## Наблюдаемый результат

Estate Race остаётся детерминированной игрой с одним локальным агентским местом.
Схема манифеста первой объявляет `config.players.agentSeats`, а локальная
сессия передаёт только `agentSeatCount`. Последние N серверно выданных мест
помечаются как агентские; неагентские места остаются человеческими.

## Общая граница

Системный драйвер агентского места использует обычную actor-scoped проекцию,
каноническую availability и только опубликованный Game Intent. Выбор проходит
тот же входной допуск, Mechanics assertions и command receipt, что и обычное
действие; состояние меняется атомарно. Повтор по тому же receipt не сканирует
кандидатов заново. Нового хранения сессии, сетевого lifecycle или отдельного
агентского режима нет; credential остаётся локальным credential контроллера.

Для Estate Race PM одобрил упорядоченный fallback до 73 элементов (изменение
лимита `maxItems` 8→73). Первые 72 невалидных кандидата не оставляют частичного
состояния, кандидат №73 фиксирует результат, а №74 отвергается схемой. Выбор
агента не получает секретов и не возвращает прямые эффекты или IR.

## Игровой результат

Поддержаны `agentControl` с receipt-derived состоянием `paused` и
`facilitatorTakeover`, а также четыре кода причины. При недоступности или
некорректном ответе система ограничивает попытки и действует по принятой
политике; передача хода человеку сохраняет обычные действия. В Estate Race
`thirdJailMovePending` отделяет обычную третью попытку выхода из тюрьмы от
последующего обязательного перемещения.

## Player Web

Общий Player Web показывает отдельную настройку только для игр, где в
`playerConfig.agentSeats` явно есть декларация. Он отправляет лишь
`agentSeatCount`, использует фиксированный минимум участников манифеста и
показывает метки мест. При паузе или malformed payload интерфейс fail-closed и
запрашивает свежий GET; takeover сохраняет обычные действия человека.

## Приёмка

- нейтральное доказательство 73 кандидатов: 72 отказа без частичного состояния,
  №73 commit, №74 schema rejection, exact retry без повторного сканирования;
- Estate Race: 53/53 package tests, balance 3/3 и compiler check;
- семь фиксированных legality/bounded-reasonableness eval fixtures: purchase,
  auction, jail, building, trade, liquidity, bankruptcy;
- bounded human+agent transcript подтверждает actor projection, secret
  isolation, обычные intents, receipt retry и fallback;
- deterministic game и отсутствие Estate Race терминов в shared production
  сохранены.

## Ограничения

Доказан только локальный mock/provider seam. Реальный provider и двухфазный
внешний вызов остаются следующей работой; transcript не является полным
терминальным матчем, а eval не доказывает стратегическую силу. S10 private
invite network остаётся следующим Estate-срезом. Общие ограничения
in-memory admission/quota остаются существующим долгом.
