# GSR-048: «Карты, деньги, поезда» — переносимый журнал партии

- **Дата:** 2026-08-13
- **Статус:** Реализовано; ИИ-интерпретация остаётся следующим отдельным этапом
- **Предусловие:** нормативная игра исполняется через Game Intent → Mechanics IR,
  а подтверждённые события сохраняются в долговечном event ledger
- **Архитектура:** ADR-084, ADR-092 и ADR-103

## Наблюдаемый результат

Ведущий может скачать из обычного экрана партии один JSON-файл с
подтверждёнными публичными событиями. В контрольном браузерном сценарии после
погрузки груза файл содержит `cargo.loaded` на той же последней защищённой
последовательности, которую вернул Runtime API, и сохраняет фактические
`cargoId` и `wagonId`.

## Общая граница

Журнал строит общий Runtime API из `SessionEventRecord` с аудиторией `public`.
Он не читает игровую `state.public.log`, не знает идентификатор этой игры и не
вычисляет правила. Хранилище аутентифицирует запрос, фиксирует живой либо
архивный жизненный цикл и читает не больше предела плюс одной записи в одном
согласованном снимке. PostgreSQL сохраняет необязательные `metricChanges`
вместе с событием, поэтому долговечный и in-memory режимы дают одну проекцию.

## Безопасная выдача

Файл не содержит `principalId`, `commandId`, `receiptId`, `actionId`, `actorId`
или Mechanics audit. Живой журнал доступен аутентифицированному principal
сессии; после архивирования — только ведущему. Player Web передаёт credential
через HttpOnly BFF, сохраняет точные серверные байты и не пропускает внутренние
заголовки. Превышение лимита возвращает ошибку без усечения документа.

## Доказательства

- каноническая JSON Schema и производные типы проходят AJV и проверку drift;
- нейтральные runtime-тесты проверяют фильтрацию, порядок, версионную границу,
  live/archive доступ, лимиты и отсутствие мутаций;
- тесты PostgreSQL проверяют ограниченный запрос и сохранение `metricChanges`;
- Player Web проверяет точные байты BFF, отсутствие credential в браузере и
  доступную ссылку скачивания;
- настоящий CMT browser flow проверяет событие погрузки на точной последней
  последовательности без game-specific ветки в общих слоях.

## За пределами среза

ИИ-разбор, учебная рефлексия, оценка участников, CSV/PDF, публичная ссылка и
отдельное хранилище не входят в GSR-048. ИИ-интерпретация может использовать
подтверждённый журнал только после отдельного архитектурного решения о
происхождении, приватности, версии модели и контроле ведущего.
