# GSR-051: «Карты, деньги, поезда» — ИИ-черновик итогового разбора

- **Дата:** 2026-08-27
- **Статус:** Принят к реализации
- **Предусловие:** нормативная партия завершена, финальные рейтинги рассчитаны,
  переносимый журнал ADR-103 доступен ведущему
- **Архитектура:** ADR-071, ADR-103, ADR-104

## Наблюдаемый результат

После подтверждённого завершения партии ведущий запускает один ИИ-разбор и
получает сохраняемый черновик на русском языке. Он видит отдельно факты,
интерпретации и вопросы для рефлексии, а каждое содержательное утверждение можно
сопоставить с номерами событий исходного журнала.

## Игровой вход

В общий provider-конверт CMT передаёт уже существующие данные:

- переносимый журнал полной доступной границы;
- публичное конечное состояние с двумя рейтингами, деньгами, техникой,
  незавершёнными обязательствами и методическими паузами;
- `meta.training` закреплённого пакета с компетенциями управления изменениями,
  переговоров и стратегического мышления.

Новая игровая оценочная формула, скрытая психологическая модель и ручной
пересчёт итогов не добавляются.

## Пользовательский путь

1. Кнопка появляется в CMT только при `public.session.status = finished`.
2. Ведущий запускает генерацию; повторный щелчок не создаёт параллельный вызов.
3. Во время запроса интерфейс показывает понятное ожидание и оставляет доступным
   обычный итог партии.
4. Успешный черновик сохраняется и возвращается после перезагрузки или
   восстановления сессии без нового вызова модели.
5. При ошибке ведущий видит безопасное объяснение и может явно повторить
   попытку; журнал и финальные результаты остаются доступными.

## Проверяемые ограничения

- обычный участник не может создать или прочитать черновик;
- две конкурентные команды не создают два успешных черновика;
- готовый черновик не регенерируется;
- факт с отсутствующим или выходящим за границу номером события отклоняется;
- provider output не содержит игрового действия и не меняет state version либо
  event sequence;
- PostgreSQL и in-memory режимы дают одинаковый продуктовый статус;
- CMT browser proof проходит через обычную кнопку после финала и после reload
  показывает тот же draft id и journal SHA-256.

## За пределами среза

Редактор ручных версий, публикация участникам, персональная психометрия,
сравнение разных партий, PDF, поиск по архивам и общий production-провайдер для
AI-driven игр не входят в GSR-051.
