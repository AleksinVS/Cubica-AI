# Векторизация игровой карты

Актуальный результат — `ИТОГ — границы областей из исходника без отступа.svg`. Внутренние границы распознаны заново непосредственно из исходного PNG в полном разрешении; старая внутренняя сетка и защитный отступ от границ стран не использовались.

Для задач, где линии должны технически доходить до оси контура страны, предназначен `ИТОГ — сетка со стыками к границам стран.svg`. В нём есть 159 коротких микростыков длиной не более 11,851 px. Каждый стык добавлен только у подтверждённого исходником контакта и расположен под толстым контуром страны. Других дорисованных продолжений нет.

Контрольные изображения начинаются с `ПРОВЕРКА`, численные метрики находятся в `ОТЧЁТ — качество распознавания.json`. Актуальные SVG начинаются с `ИТОГ`; остальные SVG в папке — сохранённые ранние варианты.

Важно: версия со стыками решает разрывы у границ стран. Разрывы, полностью скрытые под подписями, номерными метками и декоративными объектами, намеренно не восстанавливались, поскольку их точная форма в исходном изображении не видна.
