# AGENTS: публичные контракты

## Область действия

Этот файл дополняет корневой `AGENTS.md` для `packages/contracts/`. Здесь лежат
межкомпонентные структуры, поэтому изменение может связывать несколько
сервисов, клиентов и игровых пакетов.

## Источник истины

- JSON Schema или OpenAPI является каноническим описанием формы данных.
  TypeScript-типы и другие языковые представления генерируются либо проверяются
  на соответствие этому источнику.
- Не заменяйте декларативную схему ручными type guards, Zod или другой
  изолированной реализацией. Ручная проверка допустима только для семантики,
  которую нельзя корректно выразить формой схемы; не дублируйте в ней типы,
  required-поля и структуру.
- Схема и сгенерированные артефакты меняются в одном изменении через принятый
  генератор. Не редактируйте производный файл вручную.

## Архитектурная граница

Изменение публичной структуры, версии, совместимости, видимости или владельца
данных является архитектурным. До реализации получите решение PM и обновите ADR
с `docs/architecture/PROJECT_ARCHITECTURE.md`. Внутренняя редакционная правка,
не меняющая контракт, такого согласования не требует.

Общие игровые контракты используют нейтральные понятия и не содержат
идентификаторов, терминов или исключений конкретной игры.

## Проверка

Запускайте schema validation, генерацию в режиме `--check` и тесты соответствия
затронутых потребителей. Для новой общей игровой возможности добавьте
нейтральную фикстуру, не зависящую от конкретного пакета.
