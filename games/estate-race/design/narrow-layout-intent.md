# Estate Race: намерение узкой компоновки

Дата: 2026-08-12. Статус: оригинальный game-owned дизайн-референс Cubica.

При ширине рабочей области меньше 760 px поле остаётся первым и главным
объектом. Общий `map-first` layout платформы может уменьшить или вписать
поверхность 1400×1000, но игровая сцена не меняет координаты и не создаёт
отдельную мобильную механику.

Порядок чтения на узком экране:

1. название, номер хода и активный участник;
2. полное поле с подтверждёнными фишками и состояниями собственности;
3. обычные DOM-кнопки и формы доступных серверных действий;
4. участники и экономика;
5. контекст решения;
6. необязательный вопрос для разбора и подтверждённый итог.

Минимальный смысл сохраняется без hover и без canvas-ввода: каждое действие
доступно в DOM-пути, а параметризованные действия выполняются только через
формы хоста. Системный `prefers-reduced-motion: reduce` отключает появление,
переход фазы, движение фишки и проявление владения; новое подтверждённое
положение и все текстовые статусы показываются сразу.

Намеренная граница: текущий публичный plugin API не передаёт отдельную игровую
настройку reduced motion. Сцена использует стандартный сигнал браузера и не
требует изменения shared Player Web или схемы сессии.

Векторный референс задаёт только композицию, визуальную иерархию и стиль. Он не
является источником цен, аренды, сборов или состояния партии: живой интерфейс
получает все такие значения из опубликованного игрового манифеста и
подтверждённой серверной проекции.
