# AGENTS: общий runtime API

## Область действия

Этот файл дополняет корневой `AGENTS.md` для `services/runtime-api/` — общего
серверного исполнения игровых сессий. Runtime знает нейтральные контракты и
операции, но не смысл конкретной игры.

## Инварианты

- Не добавляйте идентификаторы игр, предметные `if/else`, специальные маршруты
  или импорты реализации конкретного пакета.
- Новая механика сначала выражается существующим Game Intent → Mechanics IR.
  Общие операции описывают выбор, фильтрацию, порядок, вычисление, планирование,
  атомарную композицию и изменение данных, а не игровой эффект.
- Если язык недостаточен, game-scoped extension выполняется за пределами
  процесса runtime через принятый ограниченный контракт. Не переносите его код
  или права внутрь сервиса ради удобства.
- Новая публичная операция/схема, право, граница доверия, источник истины либо
  существенно иная эксплуатационная модель требуют одобрения PM и ADR.

## Валидация

JSON Schema и OpenAPI остаются источниками истины для формы контрактов и
проверяются стандартными валидаторами. Ручной guard не должен повторять их
структурные правила. Отдельный semantic checker допустим для межполевых
инвариантов, типов опубликованной модели, ограничений стоимости и авторизации;
его назначение должно быть явно отделено от schema validation.

## Проверка

Запускайте самый узкий тест изменённой операции, маршрута или инварианта и
дешёвую проверку схем/типов. При изменении общей механики добавляйте нейтральную
фикстуру; при изменении публичного контракта проверяйте всех затронутых
потребителей и соответствующий архитектурный обзор.
